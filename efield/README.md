# efield — electric field and electron drift in the XAMS TPC

Plan: `docs/efield_plan.md`. First implementation: a full 3D COMSOL 6.2 model, generated by a script (no clicking).

```bash
efield/comsol/run.sh --cases sept,cma,cmb,refa          # build + solve (~1.5 min, 2.3 M elements, all cases in one sweep)
/Users/acolijn/miniconda3/envs/g4/bin/python efield/comsol/plot_rz.py   # (r, z) plane through the SiPM + drift lines
```

| File | What |
|---|---|
| `cases.yaml` | HV cases (electrode voltages), resistor chain, SiPM model (grounded 3 × 3 mm plane, 1 mm recessed), liquid level |
| `comsol/make_model.py` | writes `comsol/build/XAMS_efield.java` from `geometry.yaml` + `cases.yaml` (COMSOL Java API) |
| `comsol/run.sh` | generate → `comsol compile` → `comsol batch` → `build/XAMS_efield.mph` (open in the GUI) + `build/run.log` → `parse_log.py` |
| `comsol/parse_log.py` | CHECK / MAP lines of the log → `results/efield/comsol/checks.json`, `maps_rz.npz` |
| `comsol/plot_rz.py` | `results/efield/comsol/rz_<case>.png`, `drift_<case>.json` |

Model: inside of the grounded vessel; PTFE bucket with LXe (ε 1.96) up to the level, GXe (1.00) elsewhere; meshes as solid
conducting discs (etched holes not resolved) with their support rings; PTFE cylinder (ε 2.1) with the 0.875 mm gap above
the cathode; copper field-shaping rings at the chain potentials; PTFE PMT holders; PMTs as conducting boxes at their HV
(assumption); SiPMs as grounded 3 × 3 mm planes at the bottom of 1 mm deep holes in the PTFE inner wall.

Checks (`checks.json`): drift field at the centre / nominal = 1.006–1.009; gas / liquid field in the gap = 1.96; chain
current 150 nA at 750 V (5 GΩ); wall potential at the SiPM height as expected from the chain.

COMSOL notes:
- the network licence comes from the UvA licence server (must be reachable);
- COMSOL's default security setting forbids Java code to write files outside its own folders: the model is saved with
  `comsol batch -outputfile`, and the (r, z) map is printed to the log (`MAP` lines). The 3D box exports around the SiPMs
  (`export: [sipm]` in `cases.yaml`) need *Preferences → Security → File system access: All files* (the user's choice).

## Mesh cell (gate / cathode)

```bash
efield/comsol/run_cell.sh gate    --cases sept,refa,cmb50,bs2,bs3            # 2D plane through the hole centres
efield/comsol/run_cell.sh cathode --cases sept,cmb50 --map3d                 # + 3D field near the foil
/Users/acolijn/miniconda3/envs/g4/bin/python efield/comsol/plot_cell3d.py cathode sept cmb50   # interactive 3D (HTML)
```

| File | What |
|---|---|
| `comsol/make_cell.py` | quarter cell of the etched mesh (holes 2.45, bars 0.15 × 0.15 mm, pitch 2.6 mm; periodic by symmetry); drift side with a fixed field (surface charge), far side a fixed-potential plane (anode / bottom screen); all cases in one sweep; `--map3d` prints the 3D field near the foil |
| `comsol/run_cell.sh` | generate → compile → batch → `plot_cell.py` |
| `comsol/plot_cell.py` | `results/efield/comsol/cell_<el>_<case>.png` (|E|, equipotentials, drift lines; 3 cells mirrored), `cell_<el>.json` |
| `comsol/plot_cell3d.py` | `results/efield/comsol/cell3d_<el>_<case>.html` (plotly, 3 × 3 cells; not in git: 10–25 MB each, regenerate) |

Results (2026-10-12): gate — all drift lines pass, focused into ~0.6 mm channels at the hole centres, zero-field point
~0.8 mm below each bar. Cathode — the reverse field pulls electrons from a layer above the cathode through the holes
(lost for S2): Sept 1.17 mm, BS2 1.22 mm, REF-a 0.86 mm, CM-B 0.23 mm, BS3 0; slow drift just above that layer.

Gate + anode (`run_cell.sh stack` = anode aligned with the gate, `stackx` = anode shifted half a pitch in x; liquid
surface at 4 mm, top screen at 18 mm): aligned — electrons pass the anode holes and land on the bars from above (gas
path 5.3 mm); shifted — they land on the underside of the bar above each gate hole (3.9 mm). Electroluminescence per
electron (140·E − 116·p, p = 2 bar) is 8–18 % higher when shifted (Sept 347 → 375, REF-a 144 → 166, CM-B 98 → 116), so
a misalignment between the meshes gives a moiré S2-gain pattern over x-y.
