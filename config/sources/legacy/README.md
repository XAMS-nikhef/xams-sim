# Old source files (isotope at a fixed place)

Each file here is an isotope with its own `position_mm` (estimates from before the survey of 2026-11-17). Runs that
name them still resolve (`source: cs137_side_zm8` falls back to this folder). New runs: an isotope of `config/sources/`
plus a `position:` of `config/positions.yaml`. Remove this folder when all simulations are rerun.
